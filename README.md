# Neural Core AR (MindAR + A-Frame)
Markerless-app, browser-based image-tracking AR demo. Ved Jignesh Shah, A049, AIML A1-2.

1. Run `blender/make_neural_core.py` in Blender; copy `neural_core.glb` into `assets/`.
2. Compile `assets/target.png` at https://hiukim.github.io/mind-ar-js-doc/tools/compile and save as `assets/targets.mind`.
3. Push to GitHub, enable Pages (Settings > Pages > main / root). Open the URL on a phone, show the target on another screen. Add `?stats` for fps.
